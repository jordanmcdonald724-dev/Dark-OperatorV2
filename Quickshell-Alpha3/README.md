# Dark Operator — Quickshell Alpha 3

Independent build. Alpha 1 and Alpha 2 are not patched or overwritten.

- one coherent bottom shell instead of a fake top station strip
- five persistent Station project contexts
- pinned application launch targets
- real Hyprland running-window task area
- click running window to focus/restore
- click active running window to minimize
- middle-click running window to close
- true fullscreen automatically hides the entire Dark Operator shell
- no reserved screen area
- restrained Dark Operator graphite/cyan identity

Install after uploading this folder to the repository:

```bash
cd /home/jordan/Dark-OperatorV2
git fetch origin
git reset --hard origin/main
cd Quickshell-Alpha3
chmod +x install.sh rollback.sh
./install.sh
```
